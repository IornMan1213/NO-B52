# What is left of the donor bomber

Written by the B-52 build (`B52Tools.B52DonorAudit`); do not edit by hand. The B-52 is built starting from the
game's FastBomber1 prefab. This lists everything still taken from it, compared with the donor prefab setting by
setting. A setting equal to the donor's is listed as a donor value, even where the value happens to be right for
the B-52: it was not chosen for the B-52. References between the B-52's own objects are wiring and are not counted,
nor is runtime state the game sets itself at spawn (ids, hit points, speed, g, fuel level and the like).

## Summary

- Components taken from the donor (copied, moved across or cloned): **193**; settings in them: 17266, of which **2739 still at the donor's value** (16%).
- Game components the builder added fresh (B-52 values throughout): 1 (Airbrake x1).
- Aircraft parameters: copied from the donor's; 0 of 178 settings still at the donor's value.
- Aircraft definition: copied from the donor's; 4 of 50 settings still at the donor's value.
- Game assets used: 45 (below).
